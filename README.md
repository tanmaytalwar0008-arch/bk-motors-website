# BK.MOTORS Website Prototype

This repository contains a simple static prototype for BK.MOTORS — a premium-looking pre-owned two-wheeler showroom site.

What is included
- index.html — Homepage, services, inventory list (loads vehicles.json)
- vehicle.html — (planned) Individual vehicle detail page (not implemented in the static prototype)
- styles.css — Basic styles
- vehicles.json — Inventory data (draft)

How to preview
1. Clone the repository.
2. Serve the files with a static server (e.g., `npx serve` or `python -m http.server 8000`).
